## 它是什么

这个仓库从名称看是收集各家 AI 工具系统提示词与模型资料的集合。README 在赞助段落中称其为「the most comprehensive repository of AI system prompts」，但正文没有项目标题、功能说明或目录索引，主要由安全提示、赞助与捐赠入口、Discord 社群和联系方式组成。它面向想研究不同产品如何设定系统提示词、比较行为边界的开发者和研究者，也适合安全团队当作提示词泄露风险的案例库。README 自己的安全提示写得很明确：暴露的 prompt 或模型容易成为攻击目标，并推荐了 ZeroLeaks 服务。仓库同时带有 LeaksLab Discord、Trendshift 和 DeepWiki 等徽章。

## 值得注意的设计

从 README 能看到的「设计」主要在资料集的包装和社区运营层面，而不是技术架构。它把仓库当成持续更新的资料集，用 Discord 和 issue 收集反馈，用赞助位、Patreon、Ko-fi 和加密货币地址维持项目；README 还标注了 `Latest Update: 12/07/2026`，作为活跃度的信号。技术层面的采集、去重、版本对照和真实性校验流程，README 完全未说明。

另一个明显选择是把提示词泄露同时当作研究素材和安全风险来处理。README 开篇不是介绍收录内容，而是警告 AI 创业公司保护数据，并把 ZeroLeaks 作为应对 prompt injection 与 system prompt extraction 的服务推荐出来。README 未说明 ZeroLeaks 与仓库维护者之间是否存在商业关系。

## 边界与风险

最关键的是授权与来源不明。README 没有许可证信息，也没有说明这些 prompt 是原始泄露、逆向还原还是官方公开材料，更没有说明再分发条件。这些资料可能涉及厂商版权、商业秘密或平台条款，使用前应逐项核对来源和适用法律。README 自身的警告也承认，暴露的 prompt 和模型会成为攻击目标。

仓库的可验证性也有限。README 没有收录清单、工具版本、抓取日期或校验值，无法判断某份 prompt 对应哪个产品版本；`Latest Update: 12/07/2026` 没有说明日期格式，若按美式月/日解读甚至晚于本次抓取的 2026-11-24，不能据此判断实际维护状态。README 也没有提供可运行代码或测试，质量完全取决于维护者的人工整理。

维护模式同样需要留意。README 只给出一个 X 账号、一个 Discord 用户名和一个邮箱，赞助与捐赠是主要支持方式，未说明审阅流程、贡献规范或安全披露政策。它更适合作为线索库和对照材料，不适合作为需要稳定接口或法律保障的生产依赖。
