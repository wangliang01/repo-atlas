## 它是什么

sprite-stacking 把四张像素画视图变成可旋转的伪 3D sprite。它取顶、侧、前、后四个正交视图都覆盖的体素，切成层片，每层旋转、按俯仰压扁并上移 1px，形成 sprite stack。

## 怎么上手

`npx skills add danielwh2/sprite-stacking`，或把 `skills/sprite-stacking` 复制到 Agent 的 skills 目录。需要 Python 3 + Pillow + NumPy；也可以直接跑 `views_to_slices.py`。

## 值得注意的设计

除了核心切片，它带一个独立 HTML viewer：转盘、场景、切片扫描、爆炸视图和 Play 模式，还有昼夜、雨雪、阴影和 16 方向 sprite sheet 导出。对像素游戏来说，这比手动画 8 方向省很多事。

## 边界与风险

MIT。它不是真 3D 建模，四视图对不齐就会雕出错误体积；生成的精灵仍有美术风格和版权问题，viewer 性能也取决于浏览器。编辑判断：适合独立游戏快速做可旋转道具，不适合复杂角色。
