## 它是什么

VoiceStudio 是一个本地优先的 AI 语音工作台，覆盖声音克隆、音色设计、视频配音、听写、转录、旁白和批量任务。默认引擎是 k2-fsa/OmniVoice，Model Manager 里还列出数十种可切换的引擎；模型按需下载，应用在下载前会先询问。它不只是桌面软件：README 列出 macOS、Windows、Linux、Docker，以及仍属预览的 Android 和 iPhone/iPad 版本，还提供本地 API、MCP、可复用 recipes 和 watch folders，方便把语音能力接进其他流程。免费版不需要账号，Pro 和 Cloud 是可选的闭源服务。它适合播客、短视频、有声书和需要批量转录的团队，尤其是希望素材留在本机的人。

## 怎么上手

macOS 可通过 Homebrew 安装，README 标注需要 macOS 13.3+ 和 Apple Silicon，本地引擎使用 Metal：

```sh
brew tap debpalash/tap
brew trust --cask debpalash/tap/voicestudio
brew install --cask debpalash/tap/voicestudio
```

Windows 10/11 x64 使用 PowerShell：

```powershell
irm https://voicestudio.sh/install.ps1 | iex
```

Linux x64 可以走 AUR、Snap、DEB、AppImage 或一行脚本：

```sh
curl -fsSL https://voicestudio.sh/install | sh
```

Docker 用户可运行 `ghcr.io/debpalash/voicestudio:stable`，README 给出的本地 CPU 示例会把服务绑定到 `127.0.0.1:3900` 并要求设置 `OMNIVOICE_API_KEY`。从源码运行需要先克隆仓库，再执行 `bun run dev`，它会安装 JavaScript 依赖以及在受支持的本地后端下安装 Python 依赖，也可单独运行 `bun run setup:api` 重建 Python 环境。没有 GPU 时应用仍可完整使用，只是速度更慢；移动端要求 Android 10+ 或 iOS/iPadOS 17+，且属于预览状态。

## 值得注意的设计

引擎与界面分离是这套工具的主轴：Electron 前端负责工作区、模型管理和导出，Python 后端负责推理，默认引擎只是 Model Manager 中的一个选项，用户可以只下载自己需要的模型。平台加速按引擎区分，原生 GGUF 引擎支持 AMD、Intel 和 NVIDIA 上的 Vulkan，Windows 与 Linux 上的 OmniVoice GGUF 会自动选择 GPU 和模型尺寸；ROCm 支持则是实验性的，只覆盖部分 RDNA 2 RX 6000 显卡，并把 GPU 转录交给独立的 CTranslate2 进程，以保留 CPU 回退路径。性能预设保存前会在离线的子进程里验证改动后的引擎选择，避免装坏的运行时把主流程一起拖垮。自动化方面，本地 API、MCP、recipes 和 watch folders 让配音、转录和旁白可以排成批处理任务。

## 边界与风险

应用代码采用 AGPL-3.0，允许按其条款商用，但 Pro 是闭源付费版本，Cloud 仍标注为「coming soon」；模型权重、音色和生成结果另有许可证，README 特别指出默认 OmniVoice 权重是 CC-BY-NC 非商用，接客户项目前必须在 Model Manager 中逐个确认。移动端、Windows on ARM 和 Intel Mac 的本地能力都有限制：前两者是预览或实验状态，Intel Mac 只能运行界面并连接另一台机器上的后端。ROCm 只支持列出的少数显卡，RX 6500 XT 被明确排除。声音克隆要求取得说话人许可，README 附有禁止未授权克隆、冒充和欺诈的声明。README 未给出统一的内存或显存下限，性能数据分散在单独文档中；部署前应结合目标引擎和硬件查看对应的性能说明。
