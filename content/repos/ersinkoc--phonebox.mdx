## 它是什么

PhoneBox 把一台旧 Android 手机变成电脑的桌面面板：桌面端跑一个小型 agent，手机端跑全屏应用，两者通过 USB 或 Wi-Fi 通信。面板可以显示 CPU、GPU、内存、磁盘、网络和 ping，也能查看 Claude、Codex、Antigravity 的配额与重置时间，列出本地 AI 编码会话，并在手机上处理权限提示。它还提供音乐、麦克风、OBS、快捷键、宏、天气、日历、待办、番茄钟和 Home Assistant 控制。README 说明它支持 Windows、Linux 和 macOS，不需要 root、PhoneBox 账号或云服务。

## 怎么上手

需要一台 Android 5+ 手机（README 建议 Android 6 或更新）和支持的电脑。USB 方式需要数据线与 USB 调试；Wi-Fi 配对则两者都不需要。发行版 agent 自带 .NET 运行时，不必另装。

Windows 10/11 x64 在普通 PowerShell 窗口执行：

```powershell
irm https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.ps1 | iex
```

Linux 或 macOS 以当前用户执行：

```sh
curl -fsSL https://raw.githubusercontent.com/ersinkoc/phonebox/main/setup.sh | bash
```

安装脚本会下载最新 release、校验 SHA-256、提示缺失依赖和开机启动选项，并打开设置页 [http://127.0.0.1:8765](http://127.0.0.1:8765)。它也可以通过 USB 安装手机应用。之后在设置页的 Pages 里选模板、拖放和缩放控件，保存后用 Live preview 查看实时数据。

USB 连接需要打开开发者选项与 USB 调试，并在手机上接受授权。Wi-Fi 默认关闭，要在设置页开启 `General → Wi-Fi & Tailscale → Let the phone connect without the USB cable`，保存并重启 agent，再选择通过 Wi-Fi 配对，扫描二维码并核对校验码。手机应用不在任何应用商店，只能从仓库 release 获取。

## 值得注意的设计

连接层把权限留在电脑一侧。桌面设置服务只监听 `127.0.0.1:8765`；USB 通过 `adb reverse` 暴露一个独立的 loopback 端口，并使用手机生成、agent 经 adb 读取的密钥做 TLS pinning。可选 Wi-Fi 在 8766 端口使用 HTTPS、固定证书和配对密钥。手机按 ID 请求预先配置的动作，命令和集成凭据不离开电脑。这比把完整控制接口直接暴露到局域网更收敛。

面板采用可视化编辑器加页面模型。README 列出 131 个 widget、30 个模板、多页面、横竖屏布局和 12 × 6 网格，Smart Stack 可在单个槽位里放最多 12 个 widget。Live preview 能带真实数据预览未保存的修改，多个手机可以各自使用不同布局，一台手机也能在配对的电脑之间切换。

数据采集按平台选用不同后端。Windows 使用系统计数器、`nvidia-smi`，并可接 LibreHardwareMonitor；Linux 媒体走 `playerctl`、音量走 `wpctl` 或 `pactl`；macOS 媒体走 `nowplaying-cli`，并以 Spotify 或 Music 作为回退。README 的平台表同时说明这些能力受硬件、已安装工具和权限影响，而不是所有系统都完整支持。

## 边界与风险

Windows release agent 目前仍未签名。README 说明 SignPath Foundation 已接受项目且测试签名通过，但在正式证书签发前，SmartScreen 或杀毒软件可能警告或拦截。Android APK 使用项目自己的签名密钥，与 SignPath 无关。安装脚本通过 `irm | iex` 或 `curl | bash` 直接执行远程脚本，README 也提示先读脚本；在不受信任的网络环境中应改为手动下载并核对校验和。

平台覆盖有缺口：Windows ARM 和 musl Linux（如 Alpine）没有 release 构建，iOS 版本不存在，手机应用也不上架应用商店。桌面控件依赖宿主机硬件、工具和权限，Control Deck 的进阶功能还有额外平台要求。社区 add-on 由作者自行维护，PhoneBox 不审查也不分发，而且 add-on 可以通过 `PUT /api/settings` 修改设置，安装前需要确认其行为。

PhoneBox 本身没有遥测、分析或账号，但可选 widget 和集成会联系天气、配额、GitHub 等服务，agent 还会检查 GitHub 更新。README 未说明自动化测试的具体覆盖范围，只指向开发文档中的测试命令与发布检查。许可证为 MIT。
