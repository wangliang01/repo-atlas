## 它是什么

OpenFilm 把任何编码 Agent 变成视频 Agent，并提供能改任何东西的编辑器。你和 Agent 在同一部片子上实时协作：Agent 改什么你立刻看到，你改什么 Agent 也看到；Agent 做大部分工作，你指着一个地方说怎么改。

## 怎么上手

下载 macOS/Windows 桌面 App（自带内置 Agent），或给已有 Agent 装 Skill：`npx skills add openfilm/openfilm`，需要 Node 22.2+ 和 ffmpeg。装好后直接说“Make a 20-second launch video for my CLI, with music.”

## 值得注意的设计

四个编辑器共享同一份工程，但工作方式不同：

- Screening：看片，框选、圈选或点一个时刻，告诉 Agent 你要改哪里。
- Edit：完整时间线，剪辑、字幕、配音和调色都在这里。
- Canvas：素材规划板，把笔记、图片、片段和声音排在一起。
- Color：用 scopes、色轮、曲线和 LUT 调色。

编辑器遵循开放标准，第三方也能做。

## 边界与风险

MIT。Agent 仍要模型/API，素材和音乐有授权问题；桌面端成熟度和专业 NLE 还有差距，导出到 Final Cut/Premiere/DaVinci 可能丢效果。编辑判断：协作模型比“Agent 生成后丢给你一个 MP4”更合理，适合短视频和产品片。
