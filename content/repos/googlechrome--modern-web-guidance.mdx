## 它是什么

Modern Web Guidance 把 Web 平台的专业知识、最佳实践和浏览器兼容数据做成 Agent Skill，按需把针对性指南送进上下文。它要解决的是：Agent 的训练数据里堆满旧代码，于是给本来有原生方案的任务生成一堆 JavaScript。

## 怎么上手

`npx modern-web-guidance@latest install` 启动安装向导，需要 Node 22+。不想安装也可以直接试 `search`、`retrieve` 和 `legacy-scan` 三个子命令。

## 值得注意的设计

指南按 UX、CSS 布局、性能、表单与 UI、可访问性等学科组织，覆盖 View Transitions、container queries、Popover、锚点定位等新能力；内容经过 eval 裁剪，强调 token 效率。`legacy-scan` 还能扫描仓库里的旧模式。

## 边界与风险

Apache-2.0，由 Chrome/Edge/Firefox/MDN 团队共同维护，但仍不是标准本身。指南会随平台演进，`legacy-scan` 只报告不自动修；它也不知道你的浏览器支持矩阵和业务约束，采纳前要自己判断。
