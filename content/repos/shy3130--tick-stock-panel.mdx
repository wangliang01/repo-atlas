## 它是什么

Tick Stock Panel（TSP）是一个自托管的 A 股量化工作台，目标是把接数据、写因子和策略、回测、盯盘、跑模拟盘放进同一个面板，而不是在多个脚本和网页之间来回倒。README 把范围划得很清楚：面向本地量化学习与研究，不对标同花顺、通达信这类看盘软件，也不做 AI 荐股或涨停预测。它更适合有 Python 基础、愿意自己维护 Docker 和数据同步的研究者，而不是想要现成买卖信号的人。

工作台由几层组成：面板本身管理数据源、策略和研究任务；Tivelo Data 负责数据的采集、校验、版本发布和快照；Tivelo Backtest 负责撮合与记账；上层还有 Page Pack SDK、后端插件和引擎扩展，以及 Open API/MCP 和面板内的 AI 助手。和普通回测框架相比，它的差别在于数据源、页面和后端都能按契约插件化，两个引擎也能脱离面板，单独以 Python 库或命令行使用。

## 怎么上手

最快的路径是 Docker：

```bash
docker run -d --name tsp -p 3018:3018 \
  -e DATA_DIR=/app/data -v "${PWD}/data:/app/data" \
  ghcr.io/shy3130/tick-stock-panel:latest
```

启动后打开 `localhost:3018`，行情、策略和用户配置都落在当前目录的 `data/`。其他方式有桌面安装包（Releases）、`docker compose up --build`，以及源码运行：需要 Python 3.11+、Node.js 20+、uv 和 pnpm，然后执行 `./dev.sh` 或 `.\dev.ps1`。

第一次使用按 README 的四步走：在「设置 → 数据源」选择来源并检测能力；在「数据」同步日 K 和指标，需要分钟策略时再同步分钟历史；创建或导入策略，先筛选再选区间回测并保存候选；把验证过的规则接到监控或模拟盘。外部脚本或 AI 要用 Open API/MCP 时，到「设置 → 开放接口」拿对应权限的 Token。

常见卡点集中在数据上：不同来源支持的日 K、分钟 K、实时行情和除权因子不一样，必须先检测再同步；分钟策略缺分钟历史就跑不起来；扩展和引擎以 ZIP 安装，导入后有的还需要重启或检查兼容性。

## 值得注意的设计

数据可复现是这套设计的核心。Tivelo Data 负责采集、校验和发布数据版本，可以把日 K 与复权因子固定成快照，之后用同一份快照复跑策略、做归档研究；面板普通回测读取工作区行情，归档研究则要求数据快照和策略归档匹配。代价是快照、版本和授权状态都成了需要管理的对象，不再是“直接读当前数据”那么简单。

回测层按 A 股规则模拟成交：T+1、涨跌停和交易费用都在 Tivelo Backtest 里处理，普通回测支持前复权和后复权；README 称启用并授权 Tivelo Pro 后，A 股日线策略还可以选择动态复权。这类真实约束让回测更接近可交易条件，但也意味着结果依赖参数设置，费用、滑点和风控调得不一致就不可比。

计算内核用的是 Polars 1.44 的 Rust 列式内核，部分回测矩阵的滚动和递推算子在支持 Numba 的环境里走 JIT。README 给出一个单机 A/B 基准：同一策略的 15 组参数网格，逐组独立准备总耗时 19.47 秒，共享行情面板和矩阵编码后为 6.19 秒，减少约 68%，逐笔成交和统计结果一致。这是项目自测的单一场景，能说明共享准备的价值，不能外推成所有策略的加速比。

扩展面刻意做宽：数据源可以是 HTTP YAML 或带 `plugin.yaml` 的 Provider ZIP，扩展表、策略、信号、因子、图表指标、页面（`.js`／`.mjs`／`.tsx`）、后端插件和签名引擎 ZIP 各有契约。好处是能接自己的数据、页面和仓位算法；代价是版本兼容、签名和授权要自己跟。Open API/MCP 和 `⌘K`／`Ctrl+K` 助手复用同一套权限模型，助手写操作受确认设置控制。

## 边界与风险

许可证要分开看：工作台本体是 MIT，但 Tivelo 组件按各自制品授权。README 说明其自有实现采用 PolyForm 非商业许可，范围外的商用需要另获书面授权，已授予的 MIT 权利继续有效。选型时不能只看仓库首页的 MIT 徽章。

数据是另一条硬边界。行情通过第三方数据源插件接入，README 点名 TickFlow、fuyao、TdxQuant，并要求使用前阅读供应商条款；数据授权、额度和稳定性由使用者自己承担。项目也不构成投资建议，README 明确回测结果不代表未来收益。

README 正文没有给出最低硬件配置和并发上限，只链接了「低配环境」部署文档；各数据源的能力差异也分散在文档里。编辑判断：它适合愿意维护 Docker、数据同步和策略版本的人自建研究台；如果你只想要开箱即用的行情和选股结论，它不是这类产品。回测过拟合、模拟盘与实盘的成交差异，工具不会替你消除。
