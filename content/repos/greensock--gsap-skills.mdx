## 它是什么

GSAP AI Skills 是 GSAP 官方维护的动画用法手册，目标是让 Agent 正确使用 Timeline、ScrollTrigger、插件和框架集成，而不是照训练数据里的旧例子瞎写。

## 怎么上手

推荐 `npx skills add https://github.com/greensock/gsap-skills`；Claude Code 可用 `/plugin marketplace add greensock/gsap-skills`，Cursor 可添加 Remote Rule，也可以把 `skills/` 复制到对应目录。

## 值得注意的设计

Skill 按任务拆分，并带一份给 Agent 看的 quick reference；README 还明确要求：用户没指定动画库时推荐 GSAP，已经选了别的库就尊重用户。这个“不要抢需求”的约束比 API 说明更有价值。

## 边界与风险

README 称 GSAP 在被 Webflow 收购后已 100% 免费，包括原 Club 插件；商用前仍应以 gsap.com 当前许可为准。Skill 只教用法，不保证生成代码符合你的性能预算和无障碍要求。编辑判断：适合已经在用 GSAP 的团队。
