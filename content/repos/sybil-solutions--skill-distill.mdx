## 它是什么

`skill-distill` 回答一个具体问题：前沿模型把任务做好了，开源模型拿到正确指令能不能做同样的事？它让 Claude Code/Codex 当老师，在会话结束时指定一个学生（harness + 模型），然后循环写 Skill、跑学生、对比结果、修第一个出错点。

## 怎么上手

clone 后把 `skills/skill-distill` 软链到 `~/.claude/skills/` 或 `~/.agents/skills/`；需要 tmux、git、Python 3.10+ 和学生 harness。之后说“distill this session into a skill for …”。

## 值得注意的设计

老师拿到参考的原始 prompt、干净起始状态和 Skill，学生 harness 的全局上下文会被关掉；每版 Skill 跑三次，避免一次侥幸；只教步骤、判断、坑和检查，不把最终产物或写产物的脚本塞进 Skill。最后由人接受。

## 边界与风险

MIT。依赖 tmux 和学生 harness，跑一轮不便宜；会话日志可能含敏感信息；最终是否“学会”仍是人判断。编辑判断：这是把“提示词经验”变成可复现资产的认真尝试，但更适合愿意做评测的团队。
