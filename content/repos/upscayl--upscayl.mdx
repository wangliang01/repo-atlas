## 它是什么

Upscayl 是一款本地运行的 AI 图片放大工具。它用 Real-ESRGAN 一类模型把低分辨率图片放大，并按模型“猜”出缺失的细节，目标是放大后尽量不掉画质。README 把它定位为免费、开源的跨平台桌面应用，覆盖 Linux、macOS 和 Windows，顶部标注的当前版本是 v2.15，下载和文档都指向 upscayl.org 与 GitHub Releases。

它面向需要在本地批量处理图片的人：摄影爱好者、整理设计素材的人、修复老图的人。与只在命令行里跑的 `upscayl-ncnn` 相比，Upscayl 多了图形界面、批量队列和模型选择；与在线放大服务相比，它把计算放在本机 GPU 上，代价是必须有一块能被 Vulkan 识别的显卡。

核心分成三层：桌面应用外壳、内置的放大模型，以及独立的 `upscayl-ncnn` 推理后端。模型来自 Real-ESRGAN 研究和社区作者。README 称后端完全开源、采用 AGPLv3；仓库元数据同样标为 AGPL-3.0。

## 怎么上手

前置条件是兼容 Vulkan 的 GPU。README 说明多数核显和纯 CPU 环境跑不起来，但建议先试；社区还在 issue #390 提供了 Windows/Linux 的绕行方案。

安装按平台走：

- Linux：Flatpak、AppImage、AUR、Snap 或 ebuild；AppImage 需要在右键菜单的属性里勾选允许执行。多数发行版的应用商店也能装 Flatpak 或 Snap 版。
- macOS 12+：下载 dmg 拖进 Applications，首次右键“打开”；也可以 `brew install --cask upscayl`。
- Windows 10+：下载 exe 安装，遇到 SmartScreen 选“更多信息”再“仍要运行”。

Linux 除 AppImage 外还提供 RPM、DEB 和 ZIP；遇到兼容性问题可查 Wiki 的 Compatibility List 和 Troubleshooting，命令行用户则可以直接用 `upscayl-ncnn`。

README 没有给出首次运行的完整界面步骤，只把教程指向 `docs.upscayl.org`。按它的描述，选择图片和模型后开始放大。批量任务如果中途取消，README 提醒要等所有图片先完成放大再做后处理，否则可能出现未压缩或尺寸不对的结果。模型不够用时，可以从 `upscayl/custom-models` 取更多模型，或按 Wiki 的模型转换说明自己转。

常见卡点有三个：没有 Vulkan 显卡；Windows 没开性能模式，导致 GPU ID 的选择被系统覆盖；把失焦照片误当成“低分辨率”来救。README 明确说它不能去模糊或调整焦点。

## 值得注意的设计

编辑判断：Upscayl 的价值不在算法原创，而在把 Real-ESRGAN 加 NCNN Vulkan 的本地推理封装成可安装的桌面产品。README 的 FAQ 说模型是“猜”出细节，这也解释了它的适用边界：像素化、低分辨率图能救，失焦图救不了。

模型可替换是另一个关键设计。README 致谢里列出了 High Fidelity（HFA2k）、Remacri、Ultrasharp/Ultramix Balanced 等社区模型，同时提供自定义模型目录和转换流程，让用户按不同模型的特点换用。代价是模型与后处理能力并不一一对应：README 提到某些模型不支持某个动作时，程序会先放大完所有图片再统一后处理，所以批量任务不能按单张即时完成。

GPU 选择通过 GPU ID 暴露给用户，多显卡机器可以指定；Windows 上如果电源计划不是性能模式，系统可能覆盖这个选择。这个细节说明它把性能调优交给用户，而不是自动探测。README 的路线图也只写了两件事：修 bug，以及让更多人用上 FOSS，没有承诺具体功能时间表。

隐私方面，README 没有直接写“图片不上传”。但从安装方式、Vulkan 本地推理和 FAQ 的硬件要求看，README 描述的是在本机完成推理，它也没有提供云端接口。编辑判断：这正是它相对在线服务的核心卖点，但不要把“没有提到上传”当成经过审计的隐私承诺。

## 边界与风险

许可证是 AGPL-3.0。README 只强调了后端 `upscayl-ncnn` 的 AGPLv3；如果你修改后通过网络提供服务，AGPL 的源码开放义务需要自行确认。内置和自定义模型各自的许可证，README 未说明。

硬件门槛是硬限制：需要 Vulkan 兼容 GPU，很多核显不可用，macOS 需要 12+，Windows 需要 10+。README 未说明最低显存、单张耗时和支持的图片格式。

效果风险来自“生成细节”。README 建议对照 `COMPARISONS.MD` 的示例图判断适用性，而不是拿完全模糊的照片测试。README 也未说明遥测、崩溃上报或更新检查会发送哪些数据。模型补出来的是猜测，不是原始信息；人像、文字、证件类图片要逐张检查，不能当作证据修复。它也不能去模糊或做焦点校正。

编辑判断：Upscayl 适合有独立显卡、追求免费本地批量放大的用户；没有 Vulkan 显卡、需要修复失焦照片，或要在服务器上无头运行的人，应改看 CLI 后端或其他方案。README 未说明速度基准和与商业工具的对比数据。
