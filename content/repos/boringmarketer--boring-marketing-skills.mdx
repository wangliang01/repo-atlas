## 它是什么

Boring Marketing Skills 是 32 个给 Claude Code、Codex、Cursor 等 Agent 的免费营销 Skill。它们按客户旅程组织，覆盖调研、定位、文案、落地页、SEO、AI 搜索、广告、邮件和本地商家，全部不依赖付费工具。

## 怎么上手

`npx skills add boringmarketer/boring-marketing-skills`，或作为 Claude Code 插件安装。装好后输入 `/start-here` 并说出业务名，它会读网站和评论、写品牌文件，再告诉你下一步用哪个 Skill，首次约 3 分钟。

## 值得注意的设计

Skill 按客户旅程排列：先 start-here 建品牌上下文，再分“被找到 / 被选中 / 被联系 / 被召回 / 赢客户 / 自我营销”。这种按阶段路由的设计，比让 Agent 一次生成所有营销文案更可控。

## 边界与风险

MIT。README 说来自真实项目，但案例结果不能保证复制；部分 Skill 要联网读网站/评论，AI 搜索和 SEO 的结论会随平台变化。营销声明、广告合规和本地商家资质仍要人负责。编辑判断：适合小团队把营销流程拆成可执行清单。
