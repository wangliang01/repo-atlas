## 它是什么

ego lite 是让 Agent 跑浏览器自动化的浏览器，不是“桥接器”。Agent 在同一个浏览器里的独立 Space 工作，你继续用你的标签页；首次启动可以迁移 Chrome 数据，让 Agent 用上你的登录态、cookies、扩展和书签。

## 怎么上手

下载 macOS/Windows 应用，或 `npx skills add citrolabs/ego-lite` 只装 `ego-browser` Skill；首次跑浏览器任务会引导安装 App。然后在 Agent 里输入 `/ego-browser` 加一句自然语言。

## 值得注意的设计

它把能力包成 JavaScript 函数让 Agent 直接调用，而不是让 Agent 反复执行 CLI 命令、看结果、再执行；复杂任务可以组合成一次输出，减少工具调用和 token。页面会转成结构化 Snapshot，Agent 读完再动作。

## 边界与风险

MIT，macOS/Windows 可用，Linux 在 roadmap。继承登录态很方便，也意味着 Agent 能碰到你的账号数据；Agent 操作仍可能误点、发错内容。README 的“更快、更少 token”是项目自测。右栏的 browser-use、agent-browser 是 README 明确对比的对象。
