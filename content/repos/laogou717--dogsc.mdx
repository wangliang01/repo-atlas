## 它是什么

DogSC 是 macOS 原生的录屏与轻量剪辑工具，口号是「录得清楚，剪得轻松，运镜自然」。它把录制、剪辑、运镜、画面装饰、字幕和导出放在一个 App 里，目标用户是录教程、做产品演示、录课程或做短视频的 Mac 用户。

录制侧支持显示器、窗口、区域，以及用数据线连接的 iPhone/iPad，并可同时录摄像头、麦克风和系统声音。剪辑侧支持分割、裁剪、重排、变速和恢复剪辑，缩略图与波形随时切换，边界自动吸附；运镜支持自动跟随光标、手动缩放、3D 倾斜/透视和聚焦虚化；画面侧有比例、裁切、留白、圆角、阴影、背景和样机外框。导出支持 MP4 或 M4A、原始素材/1080p/1440p/4K、30/60 FPS，项目可以继续编辑。

和系统自带录屏相比，它的差别主要在后期：光标、摄像头、字幕、背景和运镜被当成可编辑对象，而不是录完就固定的像素。和重型剪辑软件相比，它更偏「录屏专用」的轻量流程。

## 它替掉了什么麻烦

它要替掉的是「系统录屏 + 另一款剪辑软件 + 手动运镜」这条拼接链路；README 未说明项目缘起，以下是编辑判断。系统录屏录完只是像素，光标、转场和字幕都要在剪辑软件里重做，运镜常靠放大关键帧模拟。DogSC 把这些环节收进同一条时间线，并用录制标记把录的时候和剪的时候连起来。

它的取舍也和同类拉开距离。README 说录制时可按 `⌃⌥M` 留标记，悬浮备忘录可当提词器且不会被录进画面；这两点针对的是录完再靠波形找口误、甚至重录整段的返工。编辑判断：与 OBS 这类以采集和推流为主的工具相比，DogSC 的重心明显在后期；与 Final Cut、Premiere 这类通用剪辑相比，它不追求片种全能，而是把录屏专用的光标、背景和样机外框做成预设。它也没有把录屏和剪辑拆成两条导出再导入的流程，而是让两边共用同一个项目。README 没有给出与任何竞品的对比数据，以上只是从功能覆盖做的推断。

## 跑起来要几步

从 Releases 下载 DMG，把 DogSC 拖进「应用程序」，按引导开启屏幕录制与辅助功能权限，麦克风和摄像头按需授权。界面语言在「设置 → 通用」里切换，支持简体中文和 English，切换即时生效。

当前测试版使用 Apple Development 签名，未经过 Apple 公证。首次打开如果被拦截，需要到「系统设置 → 隐私与安全性」点「仍要打开」；README 提醒只从本仓库的 Releases 下载。

从源码构建的门槛更高，需要 Apple Silicon Mac、Xcode 26+ 和自己的 Apple Development 证书：

```bash
git clone https://github.com/laogou717/dogsc.git
cd dogsc

security find-identity -v -p codesigning

DOGSC_SIGNING_IDENTITY="<SHA-1 指纹>" bash build-app.sh
open ".build/local/DogSC Dev.app"
```

构建脚本会做 Release 编译，组装图标、字体、本地化和 Sparkle，并签名整个 App；单独 `swift build` 不会生成 `.app`。开发版 `DogSC Dev`（`cn.laogou.dogsc.dev`）与正式版的偏好和系统权限相互独立，也不接收正式版更新。Xcode 不在 `/Applications` 时要用 `DEVELOPER_DIR` 指定位置，首次构建需要联网下载 Sparkle。

几个上手技巧：`⌃⌥M` 留剪辑标记；悬浮备忘录当提词器；时间线上 `⌘C`/`⌘V` 复制效果片段，`⌘⇧V` 只粘贴属性；完整快捷键在菜单栏「显示 → 快捷键速查」。

## 它把复杂度放在哪

复杂度集中在「所有效果都是可编辑对象」这一条上。运镜由自动跟随光标、手动缩放、3D 倾斜/透视和聚焦虚化组成，参数存在项目里而不是烘进视频；开场动效负责第一秒的注意力。这样录屏时不用为了镜头去移动窗口。光标侧还有样式、点击反馈、静止隐藏与时间校准；摄像头支持布局和出场动画；画面侧提供贴图、柔化和突出，以及可一键套用的场景预设。项目文件保留可编辑状态，导出不是一次性烘焙，交付时要连项目一起归档才能以后修改。

素材箱只引用原文件，而不是复制一份，好处是省磁盘、改素材能同步。

字幕和动效同样被做成可编辑层：README 说支持双语字幕、多种字体和出场动画，可导入导出 SRT；动效来自 Rive 和 DogSC Motion，参数可以直接改。改一句字幕或换一个动效不需要回到录屏，项目仍可继续编辑和导出。

声音侧支持背景音乐和音效，README 说有人说话时音乐会自动压低（ducking）；素材箱里的视频可以画中画或铺满。导出可选 MP4 或 M4A，分辨率覆盖原始素材、1080p、1440p、4K，帧率 30 或 60 FPS。

AI 助手接的是你自己的 Codex 或 API Key，可以生成字幕、配音乐、原创动效，每次修改支持一步撤销；也能在 Claude Code、Codex 里通过 MCP 编辑 DogSC 项目。这等于把「用自然语言改片」接到一个本地项目文件上，而不是把素材上传到云端服务。README 未说明实际会把哪些内容发给所选模型服务。

## 什么时候别用它

源代码是 MIT，但随附字体遵循各自的许可，见 `Resources/Fonts/README.md`；商用前要分别确认字体授权，不能把 MIT 当成整个 App 所有资源的许可。

素材箱只引用原文件的设计也有代价：原文件被移动或删除后，项目可能找不到素材，README 未说明缺失素材时的具体行为。可编辑效果越多，项目文件要维护的参数也越多，这是可编辑性换来的成本。

平台限制很明确：只支持 macOS 14+ 和 Apple Silicon（README 的 badge 如此标注）；源码构建还要 Xcode 26+ 和开发者证书。当前是测试版、未公证，系统权限、稳定性和更新节奏都要自己承担。README 未说明正式版时间表、是否有付费计划，也未说明是否支持多显示器同时录制。

安全上，未公证的 App 需要用户手动绕过 Gatekeeper，这本身是风险；README 要求只从官方 Releases 下载，是在缩小这个风险。编辑判断：功能面很全，适合愿意试 beta、用 Mac 做录屏内容的个人；不适合要稳定交付、需要 Windows 或 Intel Mac 的团队。
