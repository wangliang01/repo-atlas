## 它是什么

DogSC 是 macOS 原生的录屏与轻量剪辑工具，口号是"录得清楚，剪得轻松，运镜自然"。它把录制、剪辑、运镜、画面装饰、字幕和导出放在一个 App 里，目标用户是录教程、做产品演示、录课程或做短视频的 Mac 用户。

录制侧支持显示器、窗口、区域，以及用数据线连接的 iPhone/iPad，并可同时录摄像头、麦克风和系统声音。剪辑侧支持分割、裁剪、重排、变速和恢复剪辑，时间线可自动吸附；运镜支持自动跟随光标、手动缩放、3D 倾斜/透视和聚焦虚化；画面侧有比例、裁切、留白、圆角、阴影、背景和样机外框。导出支持 MP4 或 M4A、原始素材/1080p/1440p/4K、30/60 FPS，项目可以继续编辑。

和系统自带录屏相比，它的差别主要在后期：光标、摄像头、字幕、背景和运镜被当成可编辑对象，而不是录完就固定的像素。和重型剪辑软件相比，它更偏"录屏专用"的轻量流程。

## 怎么上手

从 Releases 下载 DMG，把 DogSC 拖进"应用程序"，按引导开启屏幕录制与辅助功能权限，麦克风和摄像头按需授权。界面语言在"设置 → 通用"里切换，支持简体中文和 English，切换即时生效。

当前测试版使用 Apple Development 签名，未经过 Apple 公证。首次打开如果被拦截，需要到"系统设置 → 隐私与安全性"点"仍要打开"；README 提醒只从本仓库的 Releases 下载。

从源码构建的门槛更高，需要 Apple Silicon Mac、Xcode 26+ 和自己的 Apple Development 证书：

```bash
git clone https://github.com/laogou717/dogsc.git
cd dogsc

security find-identity -v -p codesigning

DOGSC_SIGNING_IDENTITY="<SHA-1 指纹>" bash build-app.sh
open ".build/local/DogSC Dev.app"
```

构建脚本会做 Release 编译，组装图标、字体、本地化和 Sparkle，并签名整个 App；单独 `swift build` 不会生成 `.app`。开发版 `DogSC Dev`（`cn.laogou.dogsc.dev`）与正式版的偏好和系统权限相互独立，也不接收正式版更新。Xcode 不在 `/Applications` 时要用 `DEVELOPER_DIR` 指定位置，首次构建需要联网下载 Sparkle。

几个上手技巧：录制时按 `⌃⌥M` 留剪辑标记；悬浮备忘录可以当提词器，且不会被录进画面；时间线上 `⌘C`/`⌘V` 复制效果片段，`⌘⇧V` 只粘贴属性。

## 值得注意的设计

它把"录制时"和"剪辑时"连起来。录制阶段留下的标记，会变成时间线上可以找回的口误或重点；提词器窗口被排除在录制之外。这种设计减少了录完再靠波形找位置的时间。

运镜是另一个核心抽象。自动跟随光标意味着录屏时不用为了镜头去移动窗口；3D 倾斜、透视和聚焦虚化把平面的屏幕内容做出空间感；开场动效则负责第一秒的注意力。这些效果以可编辑参数存在，而不是烘死在视频里。

素材箱只引用原文件，而不是复制一份。好处是省磁盘、改素材能同步；代价是原文件被移动或删除后，项目可能找不到素材。README 未说明缺失素材时的具体行为。

字幕和动效也被做成可编辑层：README 说支持双语字幕、多种字体和出场动画，可导入导出 SRT；动效来自 Rive 和 DogSC Motion，参数可以直接改。这意味着改一句字幕或换一个动效不需要回到录屏，项目文件仍可继续编辑和导出。

声音侧支持背景音乐和音效，README 说有人说话时音乐会自动压低（ducking）；素材箱里的视频可以画中画或铺满。导出可选 MP4 或 M4A，分辨率覆盖原始素材、1080p、1440p、4K，帧率 30 或 60 FPS。

AI 助手接的是你自己的 Codex 或 API Key，可以生成字幕、配音乐、原创动效，每次修改支持一步撤销；也能在 Claude Code、Codex 里通过 MCP 编辑 DogSC 项目。这等于把"用自然语言改片"接到一个本地项目文件上，而不是把素材上传到云端服务。

## 边界与风险

源代码是 MIT，但随附字体遵循各自的许可，见 `Resources/Fonts/README.md`；商用前要分别确认字体授权，不能把 MIT 当成整个 App 所有资源的许可。

平台限制很明确：只支持 macOS 14+ 和 Apple Silicon（README 的 badge 如此标注）；源码构建还要 Xcode 26+ 和开发者证书。当前是测试版、未公证，系统权限、稳定性和更新节奏都要自己承担。README 未说明正式版时间表、是否有付费计划、是否支持多显示器同时录制，也未说明 AI 助手会把哪些数据发给所选模型服务。

安全上，未公证的 App 需要用户手动绕过 Gatekeeper，这本身是风险；README 要求只从官方 Releases 下载，是在缩小这个风险。编辑判断：功能面很全，适合愿意试 beta、用 Mac 做录屏内容的个人；不适合要稳定交付、需要 Windows 或 Intel Mac 的团队。
