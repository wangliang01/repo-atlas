## 它是什么

DogSC 是 macOS 原生的录屏与轻量剪辑工具，覆盖录制、剪辑、运镜、画面、光标与摄像头、导出、字幕和 AI 助手。它可以录显示器、窗口、区域或用数据线连接的 iPhone/iPad，同时录摄像头、麦克风和系统声音。

## 怎么上手

从 Releases 下载 DMG 拖进应用程序，按引导开屏幕录制和辅助功能权限。测试版用 Apple Development 签名、未公证，首次打开可能要在“隐私与安全性”里点“仍要打开”。从源码构建需要 Apple Silicon Mac、Xcode 26+ 和自己的证书。

## 值得注意的设计

它把录制和剪辑放在一个原生 App 里：录制时按快捷键留剪辑标记，时间线可吸附、复制效果，运镜能自动跟随光标并做 3D 倾斜/虚化，字幕支持双语和 SRT 导入导出。AI 助手可接自己的 Codex 或 API Key，也能通过 MCP 从 Claude Code/Codex 编辑项目。

## 边界与风险

MIT，但随附字体另有许可。当前是测试版、未公证，系统权限和稳定性要自己承担；只支持 macOS，源码构建门槛不低。编辑判断：功能面很全，适合愿意试 beta 的 Mac 用户，不适合要稳定交付的团队。
