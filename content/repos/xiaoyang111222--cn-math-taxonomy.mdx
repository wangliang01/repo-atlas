## 它是什么

cn-math-taxonomy 是一套面向中小学的知识图谱和前置诊断工具。它把知识点、先修关系和题目组织成可查询的数据，学生答错时沿先修边从高中、初中一路回溯到小学，定位真正没掌握的前置概念，再给出补学路径。

仓库名还叫 `cn-math-taxonomy`，但 README 标题列出的学科已经覆盖数学、语文、英语、物理、化学、生物、历史、地理、科学、道德与法治、思想政治。README 首页给出的总量是 4,068 个知识点、6,429 条先修边、16,419 道题、972 条课程标准条目。它对齐的是教育部课程标准和对应版本教材（以人教版为主，也有统编版、教科版等），而不是某一套机构的教研体系。

使用者包括家长、教师、自学者，以及想复用这份结构化数据的教育产品开发者。与普通题库相比，它多了「知识点—先修边」的图结构；与单纯的知识图谱相比，它又带了诊断题、掌握标准和静态诊断页面。

## 它替掉了什么麻烦

它替掉的是「孩子答错一题，只能就题论题，不知道到底卡在哪个前置概念」的麻烦。README 未说明这类工具出现前的具体诊断流程；编辑判断：传统做法是老师凭经验翻教材、家长按章节从头补，或者把错题对应的单元整段重学，既慢又容易补错层级；换一个年级、换一套教材，经验还要重新积累。

它的做法是把诊断变成沿图回溯。README 说学生答错时会沿先修边从高中、初中一直回溯到具体的小学知识点，再给出补学路径。编辑判断：这把「猜哪里不会」换成了「按依赖关系查哪里没学会」，前提是图上的边足够可信。

和普通题库的差别在结构。编辑判断：题库只记录题目和答案，答错后只知道这一题不会；这个项目把每道诊断题挂到知识点，再用先修边连到更低层概念，才能从一道题追到一串前置。和单纯知识图谱的差别在可操作性：它带了掌握标准、诊断题和静态诊断页面，不只是给人看的一张图。

README 提到数据格式参考 Marble os-taxonomy 的 `topics` 加 `dependencies`。编辑判断：这说明它借的是「知识点数组 + 依赖边数组」这套通用形状，而不是自创一套难以迁移的格式；代价是字段含义要靠文档补齐，README 对两者的字段对应做了说明。

## 跑起来要几步

最轻的方式是用在线站点：`https://math.pansgo.com/`，有知识图谱浏览和诊断两个入口；README 还给了一个配方法的演示链接 `https://math.pansgo.com/diagnose/?target=cnm_221&demo=1`。不想依赖线上服务，可以克隆仓库后起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问首页、`explore/` 和 `diagnose/`。仓库是纯静态前端，数据在 `data/`，不需要数据库或后端。

如果只想用数据，先看 `data/topics.json` 和 `data/dependencies.json`：前者是知识点数组，后者是 `{"topicId", "prerequisiteId", "strength", "reason"}` 形式的边，含义是 A 依赖 B。每个知识点带 `id`、`name`、`domain`、`grade`、`semester`、`chapter`、`type`、`description`、`mastery_criteria`、`diagnostic_question`、`standards` 等字段。

改数据后要跑校验：

```bash
python3 scripts/validate.py
```

常见卡点：题库有 `questions.json` 和按学科拆分的 `data/questions/` 两套，前端只读拆分版；改题后必须重跑 `scripts/split_questions.py`，否则测试会报不一致。旧的小学外部节点已删除，遇到 `cnm_ext_*` 要通过 `data/id-aliases.json` 映射。诊断题和先修边不是官方答案，不能直接当教学结论。

## 它把复杂度放在哪

复杂度放在「课标—教材—知识点—先修边—题目」这条可追溯链上。README 说每个知识点可以挂 `standards`，每条课标条目有 `confidence` 和页码或出处；教材章节目录按册次记录核对状态，README 明确区分「官方已核」和「非官方、待核」。编辑判断：这比只给一张图更适合需要审计来源的场景，代价是维护量落在每一条数据的出处上。

先修边分 `hard` 和 `soft`，并做了传递约简。README 说明 `hard` 是不会前者基本学不了后者，`soft` 只是有帮助；这个区分是 AI 的主观判断、未经审核。README 还说约简规则是：`hard` 边只有在存在另一条全 `hard` 路径时才删，`soft` 边有任何其他路径就删。编辑判断：所以图上「缺边」可能不是遗漏，而是被更近的路径覆盖了；用图的人要理解这点，才不会误判。

学科图是分开的。README 说数学和英语互不连边；英语内部从小学连到初中、再连到高中；物理单独成图，用到的数学写在 `mathLinks` 字段，不算先修边。编辑判断：这样避免了「学物理必须先学某个数学点」的过度约束，也保留了跨科参考。

诊断和展示都是静态的。README 说知识图谱用 Cytoscape 加 dagre 只画当前点的局部图，默认向上两层、向下一层；诊断进度和孩子档案存在本机 `localStorage`。编辑判断：这个选择降低了部署成本，也意味着没有账号、没有跨设备同步、没有服务端统计。

数据生产也有工程化痕迹。README 说 `scripts/validate.py` 只用标准库，题库有自动核验和独立第二遍复核；小学数学还有独立程序复核，但 README 明确说高中题和英语题没有做盲解。编辑判断：这让「哪些数据能信、哪些还要人工看」有据可查，而不是一句整体承诺。

## 什么时候别用它

许可证是 CC BY-NC 4.0。个人学习、教学、研究可以免费使用、修改和再分发，但需要署名；付费课程、付费 App、机构收费服务等商业使用要单独授权。`assets/vendor/` 里的 Cytoscape 等仍是 MIT，不跟随主许可证。

最大的边界是「未经教师审核」。README 反复强调知识点粒度、掌握标准、诊断题答案，尤其是先修关系，需要一线教师审核后才能用于教学、诊断或学习路径推荐。部分教材目录标着「非官方、待核」，高中和英语题没有盲解，课标条目多数是转述而非原文。编辑判断：它适合做查漏补缺的辅助工具和二次开发底座，不适合直接用于考试评分、官方教研发布或高利害决策。

数据范围也有明确缺口：README 说高中数学只做必修和选择性必修的人教 A 版，英语不出听力和口语题，部分新版教材尚未拿到官方目录。README 未说明数据更新频率承诺、错误更正时限，也没有提到服务端 API 或多用户权限。

隐私方面，孩子档案只存本机 `localStorage`，README 说统计钩子默认不发请求；但仓库本身不提供账号和加密存储，共用电脑时档案可见。商用或进校园前，数据合规要自行评估。
