## 它是什么

Remotion 用 React 组件和 Web 技术制作视频，支持三种用法：让 Agent 把想法变成视频、像普通剪辑器一样交互编辑、或把视频当代码来写。它面向视频自动化、设计系统、批量渲染和视频应用。

## 怎么上手

装好 Node.js 后 `npx create-video@latest`；文档有 1200+ 页，覆盖安装、第一支视频、Agent Skills、模板、元素、转场、字幕、字体、渲染和 Player/Editor。

## 值得注意的设计

视频由 React 组件按帧渲染，所以能复用前端生态、做参数化模板和批量生成；渲染可以走 Node.js、Lambda、Vercel Sandbox 或客户端。对“每个用户一条视频”这类需求，代码化比手工剪辑更合适。

## 边界与风险

Remotion 使用特殊许可，某些商业场景需要购买公司 license，商用前必须读 LICENSE。Node/Chromium 渲染有学习成本，复杂合成也不如专业 NLE 直观。编辑判断：批量/参数化视频的成熟选择，先确认许可再立项。
