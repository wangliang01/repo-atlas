## 要解决的问题

T-026 的详情页是“能看懂”的简介级：每节一两段，安装命令和设计机制有，但不足以让读者判断要不要采用。用户明确反馈“现在写出来的文档，太简单了”。

## 范围

- 做：
  - 每篇正文从约 600–900 字扩到 1200–2000 字；
  - “它是什么”补问题、受众、组成、同类差异；
  - “怎么上手”补前置条件、首跑步骤、预期结果、常见卡点；
  - “值得注意的设计”补具体机制、数据流、关键抽象和代价；
  - “边界与风险”补许可证、平台/硬件/模型依赖、隐私安全、运维成本、不适合谁；
  - README 说法写“README 称”，编辑判断写“编辑判断”，缺失写“README 未说明”；
  - 加一条测试，锁住新收录页至少 1000 字且区分事实与判断。
- 不做：补写 README 没有的功能；声称实际安装或测试过；改 30 篇旧详情页。
