# [T-030] 详情页目录改成「五问式」，来源不进目录

- **Status**: Pending
- **Depends On**: T-029

## 要解决的问题

现在五个二级标题（它是什么 / 怎么上手 / 值得注意的设计 / 边界与风险 / 来源）是全站共用的模板槽位，73 篇目录一模一样，读起来像验收表，不像技术博客的骨架。

## 已确认的方向

目录固定五问，标题逐字使用：

1. `## 它是什么`
2. `## 它替掉了什么麻烦`
3. `## 跑起来要几步`
4. `## 它把复杂度放在哪`
5. `## 什么时候别用它`
6. `## 来源`（保留这一节，但不出现在右栏目录）

每节第一句直接回答标题；事实继续分「README 称 / README 未说明 / 编辑判断」三层。规范已写进 `AGENTS.md` 的「写作规范（项目详情页）」。

## 范围

- 做：
  - `lib/schema.ts` 的 `REPO_DETAIL_SECTIONS` 换成新六节；
  - 右栏目录过滤「来源」（`components/pick-aside.tsx` 或其上游）；
  - 73 篇详情页：改四个旧标题，新增「它替掉了什么麻烦」，内容重新分配；
  - 全站正文补到 1500–2000 个可见汉字（当前新页 880–1531，旧页 1513–1871）；
  - 测试同步：fixture、缺节断言、字数守卫改成全站 ≥1500 汉字。
- 不做：改页面视觉、改 banner、改 `readmeSha`、改动 30 篇以外的事实结论。

## 顺序与风险

- schema 与 73 篇内容必须同一分支落地：只改 schema 会让构建红，只改内容会让校验红。
- 新增一节意味着每篇多写 150–250 字，还要从其他节压缩，才能守住 1500–2000；不是简单改名。
- 标题是目录锚点，站内如有 `#它是什么` 一类链接要一起改（迁移前先 grep）。
- 先拿 3 篇不同类型（工具 / 桌面应用 / Skill）试点，确认目录观感再全量。
